🔐 **CyberArk Identity Learning Series | Part 4: Adding Users in CyberArk Identity**

Continuing my CyberArk Identity learning journey! 🚀

Today's topic focuses on understanding how administrators add and manage users in CyberArk Identity using different identity sources.

👥 **1. CyberArk Cloud Directory Users**

These users are created and managed directly within CyberArk Identity.

🔹 Sign in to the CyberArk Identity Admin Portal.  
🔹 Navigate to **Core Services → Users → Add User** (menu names may vary).  
🔹 Enter the user's name, username, and email address.  
🔹 Configure account settings and assign appropriate roles or groups.  
🔹 Save the account and complete the required activation process.

🌐 **2. Users from an External Directory Service**

Organizations can integrate existing directories, such as Microsoft Active Directory, to manage identities centrally.

🔹 Install and configure the CyberArk Identity Connector where required.  
🔹 Establish a secure connection to the external directory.  
🔹 Configure directory integration and synchronization settings.  
🔹 Select the appropriate users or groups for synchronization.  
🔹 Synchronize identities into CyberArk Identity.  
🔹 Verify imported users and their access permissions.

⚙️ **3. Key Differences**

**Cloud Directory Users:** Managed directly in CyberArk Identity.

**External Directory Users:** Managed primarily in their source directory and integrated with CyberArk Identity.

💡 **Key Takeaway:** CyberArk Identity supports both cloud-managed users and integration with external directory services, helping organizations centralize authentication, streamline user administration, and enforce secure access policies.
